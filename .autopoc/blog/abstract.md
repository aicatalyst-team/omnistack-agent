# Blog Abstract

## Thesis
AI agent prompts need build pipelines just like application code. omnistack-agent compiles agent instructions from a single source into adapters for 6 platforms. Deploying this build pipeline as Kubernetes Jobs on Red Hat OpenShift proves that prompt engineering tooling works as containerized batch workloads.

## Target audience
Platform engineers and AI developers building prompt engineering workflows.

## Blog type
Red Hat Developer Blog

## Key points
1. Prompt engineering is becoming a build artifact problem: single source, multiple outputs, drift detection.
2. Zero-dependency Node.js tools containerize cleanly with UBI images and need no special handling.
3. Kubernetes Jobs are the right abstraction for CI-like build/validate/test workflows on OpenShift.
